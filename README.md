A chubby peach bunny with a floppy ear and a pink bow, cuddling a sleepy baby chick, drawn entirely in code: a small signed-distance-field renderer in plain Node 22 (no dependencies, no image files) shades every shape as a soft fluffy blob and writes the PNG itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
