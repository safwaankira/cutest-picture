A chubby cream kitten in a lavender scarf hugging a sleeping baby bunny, on a plain cream background. The picture was generated with HeyGen (GPT Image 2.6) and is shipped in this repository as `entry.jpg` (1024x1024, re-encoded as a quality-99 JPEG to fit the contest's 1 MiB cap); `main.ts` checks it against the contest's limits and writes it out to `/output/entry.png`. It does not draw the picture itself.

`bunny.ts` is this entry's earlier picture, a fluffy bunny cuddling a chick drawn entirely in code by a small dependency-free signed-distance-field renderer; it is kept for reference and no longer written out.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
